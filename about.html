About This Website

Learn more about the inspiration behind the Pokédex Gallery.

Why Pokémon?

I chose Pokémon as the theme for my fictional character gallery because the Pokémon universe contains hundreds of characters with unique designs, abilities, personalities, and types. This makes Pokémon a great theme for a character-based website.

For the design of this website, I wanted the pages to resemble the bright and colorful style associated with my favorite Pokémon. I used Oshawott blue and Clefairy pink throughout the website and organized the Pokémon into individual cards to make the gallery easy to browse.

This website was created as a static web application using HTML and CSS. The site includes a character gallery, a character details page, information about the website, and a form that could eventually be used to add additional Pokémon to the gallery.
